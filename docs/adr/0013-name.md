# ADR-0013 — Final name: CommitProof

Status: Accepted (K0, contract 1.0.0)

## Context

"CommitProof" was a working name. A web search on 2026-10-09 found no existing project with that name (RESEARCH §6). The name states the central guarantee under test (an acknowledged commit survives).

## Decision

Final name **CommitProof**; repository `CesarManzoCode/commitproof`; Go module `github.com/CesarManzoCode/commitproof`; binaries `commitproof`, `cpcheck`, `cpgate`, `cpreport`. Public text must not imply the project *proves* correctness: the README's first paragraph says it searches for counterexamples and reports bounded evidence.

## Alternatives rejected

- Names containing "Multigres": implies affiliation.
- Names containing "Jepsen": a trademark of Jepsen LLC and implies affiliation.
